Sayanox Programming Language

Sayanox is an original systems programming language created by Sayan Mahata. File extension: .sa

Self-hosting Native AOT x86-64 Offline packages Growing stdlib

  • Self-hosting pure-min dialect (seed → gen1 → gen2 → gen3, byte-identical)
  • Native AOT compilation for x86-64 Linux
  • Simple readable syntax with powerful systems features
  • Tools (formatter, package manager, LSP) written in Sayanox itself
  • Actively developed — one of the few original programming languages from India

About Sayan Mahata

Sayan Mahata is a System Architect and Security Researcher from Medinipur, West Bengal. He is known online as Sayan The Researcher and by the GitHub username sayan9168.

He is the Founder of Sayanox Private Limited and the creator of the original Sayanox programming language (.sa).
