## Sayanox Programming Language

**Sayanox** is an original systems programming language created by Sayan Mahata.

- **File extension:** `.sa`
- **Key features:** Self-hosting compiler, pure-min seed→gen2 bootstrap, native x86-64 AOT, offline packages, growing stdlib
- **Design goals:** Easy to read, easy to write, powerful enough for real systems work
- **Status:** Actively developed — self-hosting pure-min dialect working, many tools written in Sayanox itself

**Repository:** [github.com/sayan9168/sayanox](https://github.com/sayan9168/sayanox)

Sayanox is one of the few original programming languages being built from India with a strong focus on self-hosting and native performance.
